## 🚀 Key Features
1. **Zero Laptop Constraints & No App Installations:** Fully client-side Progressive Web App (PWA) with in-browser compiler for C, SQLite engine for RDBMS, and live Web Sandbox.
2. **Installable on Phones (PWA):** Learners can tap **"Install App"** on Android or **"Add to Home Screen"** on iOS to run offline.
3. **Strict Google Authentication:** Powered by Firebase Google Auth. Blocks fake emails and disposable phone accounts.
4. **Time-Gated Access (Drip Unlock):** Active daily window from **08:00 AM to 08:00 PM IST**. Future sessions are locked until daily requirements are met.
5. **Daily Gamification:** Interactive Canvas Spinning Wheel with sound synthesis and 8 reward perks (XP, 50/50 exam lifelines).
6. **60-Minute Timed Mock Assessment (100 Questions Daily):** Unpauseable countdown timer, 1-to-100 question palette, 50/50 lifelines, and instant grading.
7. **Daily Badges & Final Certificate:** Instant high-resolution **PNG** and print-ready vector **PDF** downloads with tamper-proof SHA-256 verification hashes.
